# Test Artifacts

## What is a Test

A test is a defined activity that verifies expected behavior against
requirements or acceptance criteria using clear inputs, steps, and outcomes.

## Test Case vs Test Scenario

| Artifact | Definition | Example |
| --- | --- | --- |
| Test Scenario | High-level goal or behavior to validate | "User can reset password" |
| Test Case | Detailed steps and expected results | Steps to request and confirm reset |

## Test Suite

A test suite is a logical grouping of related test cases, usually organized by
feature, risk area, or release scope.

## Test Plan

Definition: A document that describes the scope, objectives, approach, and
resources for a specific testing effort or release.

What it includes:

- Scope and objectives
- Test items and exclusions
- Environment and data needs
- Schedule and responsibilities
- Risks, assumptions, and dependencies
- Entry and exit criteria

## Test Strategy

Definition: A high-level, long-term approach to testing that defines guiding
principles, quality goals, and major methods across projects.

What it includes:

- Quality goals and risk approach
- Test levels and types to use
- Automation strategy and tooling
- Test data and environment approach
- Reporting and governance model

## Test Plan vs Test Strategy

| Dimension | Test Plan | Test Strategy |
| --- | --- | --- |
| Scope | Specific project or release | Organization or product line |
| Detail | Tactical and detailed | Strategic and guiding |
| Lifespan | Short-term | Long-term |
| Ownership | QA lead or project team | QA leadership |
