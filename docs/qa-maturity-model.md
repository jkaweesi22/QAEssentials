# QA Maturity Model

This model defines practical maturity levels and links each level to specific
QAEssentials sections that help teams and individuals progress.

## Maturity levels

### Level 1: Ad hoc

Characteristics:

- Testing is informal and reactive
- Limited documentation or standards
- Quality relies on individual effort

Relevant QAEssentials sections:

- Fundamentals (`fundamentals.md`)
- Testing Types (`testing-types.md`)
- Test Artifacts (`test-artifacts.md`)

### Level 2: Defined basics

Characteristics:

- Basic test cases and suites exist
- Defect reporting is consistent
- Simple release checks are used

Relevant QAEssentials sections:

- STLC (`stlc.md`)
- Defect Management (`defect-management.md`)
- Automation vs Manual (`automation-vs-manual.md`)

### Level 3: Managed

Characteristics:

- Test planning and strategy are applied
- Coverage and regression are tracked
- Quality risks are discussed regularly

Relevant QAEssentials sections:

- Test Artifacts (`test-artifacts.md`)
- Metrics and Reporting (`metrics-and-reporting.md`)
- Real-World QA (`real-world-qa.md`)

### Level 4: Optimized

Characteristics:

- Testing is risk-based and measurable
- Automation is strategic and maintainable
- Shift-left and shift-right practices are in place

Relevant QAEssentials sections:

- Automation vs Manual (`automation-vs-manual.md`)
- Metrics and Reporting (`metrics-and-reporting.md`)
- Testing Types (`testing-types.md`)

### Level 5: Strategic

Characteristics:

- Quality is embedded in culture and leadership
- QA drives governance and continuous improvement
- Quality outcomes are aligned to business goals

Relevant QAEssentials sections:

- QA Skills Mapping (`qa-skills-mapping.md`)
- QA Career Roadmap (`qa-career-roadmap.md`)
- Metrics and Reporting (`metrics-and-reporting.md`)

## How to use this model

- Identify your current level based on observed behaviors
- Use the mapped sections to build missing capabilities
- Reassess maturity after each release or major milestone
- Focus on consistent improvement, not rapid jumps
