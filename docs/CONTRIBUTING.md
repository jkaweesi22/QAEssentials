# Contributing to QAEssentials

## Purpose

Contributions keep QAEssentials accurate, practical, and consistent across QA
experience levels. The goal is to improve clarity and correctness without
adding unnecessary complexity.

## Who can contribute and how

Anyone can contribute by proposing content improvements, corrections, or new
examples that align with the mission.

How to contribute:

- Suggest edits using clear, specific language
- Propose additions that fill a real gap
- Keep changes scoped and easy to review

## Contribution principles

- Clarity: write for readers who are new to the topic
- Accuracy: verify definitions and distinctions
- Neutral language: avoid tool or vendor bias

## Guidelines for proposing changes

- State the problem your change addresses
- Reference the exact section and file
- Provide updated wording or a concrete example
- Avoid duplicating content across files

## Documentation standards

- Use consistent terminology across all files
- Prefer bullets and tables where clarity improves
- Keep sections focused and mission-aligned
- Maintain the existing structure and headings
- Use mermaid diagrams only when specified

## Review expectations

- Changes should be concise and well-scoped
- Edits must preserve accuracy and neutrality
- Large changes should be justified with a clear rationale
