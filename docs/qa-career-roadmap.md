# QA Career Roadmap

## Progression paths

- Manual QA → Automation → SDET
- QA → QA Lead → QA Manager → QA Architect
- QA → TPM / Product / DevOps-adjacent roles

## Learning focus by stage

| Stage | Focus areas |
| --- | --- |
| Early | Fundamentals, test design, defect reporting |
| Mid | Automation, API testing, risk-based testing |
| Senior | Strategy, governance, architecture, mentoring |

## Mindset shifts to level up

- From executing tests to designing quality strategy
- From feature thinking to risk thinking
- From local fixes to system-wide quality improvement
