# QA Skills Mapping

## Junior QA Engineer

Technical

- Basic test case design and execution
- Defect reporting with clear evidence
- Understanding of SDLC and STLC basics

Testing

- Smoke, sanity, and regression execution
- Exploratory testing fundamentals
- Requirement tracing and coverage

Communication

- Clear defect and test status reporting
- Basic collaboration with developers and PMs

## Mid-Level QA Engineer

Technical

- Test automation fundamentals and framework usage
- API testing and data validation
- CI basics and test environment setup

Testing

- Risk-based testing and prioritization
- Test strategy contribution
- Non-functional testing awareness

Communication

- Proactive risk communication
- Cross-team coordination

## Senior QA / QA Lead / QA Architect

Technical

- Test architecture and framework strategy
- Quality tooling selection and integration
- Observability and quality signals

Testing

- Portfolio-level quality strategy
- Governance, metrics, and audits
- Coaching on shift-left and shift-right

Communication and leadership

- Influence without authority
- Executive-quality reporting
- Mentoring and capability building
